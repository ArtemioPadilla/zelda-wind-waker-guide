# WW Guía — agent context

Sibling project to [resident-evil-4-guide](https://github.com/ArtemioPadilla/resident-evil-4-guide),
hand-built to match that repo's architecture and quality bar (its own
`CLAUDE.md` names its generator as `create-inceptor-app` from the
[Inceptor](https://github.com/ArtemioPadilla/inceptor) scaffold
`issue-driven-web-template`). This repo was **not** generated by running
that scaffold directly — the full template pulls in a large shadcn/backend
surface this lean, single-page-app-style guide doesn't need (see that
scaffold's own `dist/` output for the scope of what it includes). Instead,
the RE4 guide's already-pared-down file structure, configs, and conventions
were replicated by hand: same `localizedJson()` content-collection factory,
same nanostores + idb-keyval dirty-flag tracker pattern, same PWA setup
wired manually onto `@vite-pwa/astro`, same lean dependency set.

## Version targeted

**The Wind Waker HD** (Wii U, and Switch via Nintendo Switch Online + GameCube
pack) is the primary reference version — same call the RE4 guide made
(targeting the Wii/HD port over the GameCube original). Concretely this
means: Triforce Shards found directly (no GameCube-only intermediate charts
for shards 4-8), Hero's Charm instead of a Heart Piece on Savage Labyrinth
floor 50, Swift Sail / Hero Mode as postgame unlocks, and the Tingle Tuner
(GBA link cable content) omitted entirely since it has no function on Wii
U/Switch.

## Project-specific notes

Content lives in `src/content/*` (Astro content collections, Zod-validated),
researched from public wikis/guides (Zelda Dungeon Wiki, Zelda Wiki,
Thonky.com, Game8, ZeldaSpeedRuns) — not committed to this repo as source
documents, only as the curated JSON/Markdown content itself.

Trackers (`heartPiecesStore`, `chartsStore`, `$currentIsland`) persist state
client-side only via Nano Stores + `idb-keyval` — no backend, no accounts.
PWA precaches all static assets so the guide works fully offline once
installed.

Conventions inherited from the scaffold (matching the RE4 guide): Conventional
Commits + issue refs, never push to `main` directly for real feature work,
every PR passes `npm run check`, never import `@radix-ui/*` /
`framer-motion` / `@tremor/react` / other heavy unused UI kits, Nano Stores
for cross-island state (never React Context across islands).

## TODO — deliberately scoped out for time

This is a real, accurate, well-organized guide covering the full main-quest
progression and both primary completionist checklists (all 44 Pieces of
Heart, all 8 Triforce Charts), but it does **not** claim exhaustive 100%
coverage of every one of the Great Sea's ~49 islands or every optional
Treasure Chart. Left as follow-up work:

- **Full island roster.** Only ~30 of the Great Sea's ~49 islands are named
  anywhere in the content (mostly via Heart Piece / Chart locations); the
  `islands` collection itself covers 18 curated entries (the 6 main
  dungeons + Forsaken Fortress twice + Hyrule Castle + hub/sidequest
  islands), not a standalone page per island. A future pass could add an
  `islands` entry (or a lighter "Great Sea atlas" collection) for every
  remaining minor island (reef/rock/isle-only stops with no dedicated
  content here).
- **Full Treasure Chart list.** The game has ~40 non-Triforce Treasure
  Charts; `charts.json` covers the 10 most notable ones (tied to dungeon
  drops and named sidequest moments already verified against research
  sources) rather than all of them — most of the rest just lead to a pile of
  rupees and add little walkthrough value.
- **Per-chart shard pairing.** Community sources conflict on the exact
  chart-N → shard-island-N pairing for the HD remaster's renumbering (GC vs.
  HD renumbered them differently, and even reputable guides disagree with
  each other on some entries). Rather than assert an unverified specific
  pairing as fact, each Triforce Chart entry's `shardIsland` field
  intentionally says "Tingle deciphers it and marks the dig island" instead
  of naming one — the chart's own island and acquisition method are the
  verified, load-bearing facts.
- **Nintendo Gallery figurines.** The full game has 134 possible figurines;
  `figurines.json` covers 12 notable, well-documented ones as a sample
  lookup table (mirroring the RE4 guide's `gems.json` scope), not the full
  roster.
- **Tingle Statues (HD).** Mentioned as a sidequest card, but the 5
  individual statue locations aren't itemized — HD-exclusive content with
  comparatively thin, sometimes-conflicting documentation.
- **Savage Labyrinth floor-by-floor enemy list.** Covered at the
  "what you get / when to attempt it" level, not a floor-1-through-50
  enemy-composition breakdown.
