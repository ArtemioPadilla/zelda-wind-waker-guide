# WW Guía — agent context

Sibling project to [resident-evil-4-guide](https://github.com/ArtemioPadilla/resident-evil-4-guide),
hand-built to match that repo's architecture and quality bar (its own
`CLAUDE.md` names its generator as `create-inceptor-app` from the
[Inceptor](https://github.com/ArtemioPadilla/inceptor) scaffold
`issue-driven-web-template`). This repo was **not** generated by running
that scaffold directly — the full template pulls in a large shadcn/backend
surface this lean, single-page-app-style guide doesn't need (see that
scaffold's own `dist/` output for the scope of what it includes). Instead,
the RE4 guide's already-pared-down file structure, configs, and conventions
were replicated by hand: same `localizedJson()` content-collection factory,
same nanostores + idb-keyval dirty-flag tracker pattern, same PWA setup
wired manually onto `@vite-pwa/astro`, same lean dependency set.

## Version targeted

**The Wind Waker HD** (Wii U, and Switch via Nintendo Switch Online + GameCube
pack) is the primary reference version — same call the RE4 guide made
(targeting the Wii/HD port over the GameCube original). Concretely this
means: Triforce Shards found directly (no GameCube-only intermediate charts
for shards 4-8), Hero's Charm instead of a Heart Piece on Savage Labyrinth
floor 50, Swift Sail / Hero Mode as postgame unlocks, and the Tingle Tuner
(GBA link cable content) omitted entirely since it has no function on Wii
U/Switch.

## Project-specific notes

Content lives in `src/content/*` (Astro content collections, Zod-validated),
researched from public wikis/guides (Zelda Dungeon Wiki, Zelda Wiki,
Thonky.com, Game8, ZeldaSpeedRuns) — not committed to this repo as source
documents, only as the curated JSON/Markdown content itself.

Trackers (`heartPiecesStore`, `chartsStore`, `$currentIsland`) persist state
client-side only via Nano Stores + `idb-keyval` — no backend, no accounts.
PWA precaches all static assets so the guide works fully offline once
installed.

Conventions inherited from the scaffold (matching the RE4 guide): Conventional
Commits + issue refs, never push to `main` directly for real feature work,
every PR passes `npm run check`, never import `@radix-ui/*` /
`framer-motion` / `@tremor/react` / other heavy unused UI kits, Nano Stores
for cross-island state (never React Context across islands).

## TODO — gap-closure pass (2026-08-26)

The original build deliberately scoped down several areas for time (see git
history for the original wording of this section). A follow-up pass closed
most of them against Zelda Wiki / Zelda Dungeon Wiki / Thonky.com / Game8 /
Hyrule Blog, cross-checking each fact against at least two independent
sources before adding it. Status now:

- **Full island roster — closed.** Added a new `atlas` collection (49
  entries per locale, one per grid sector of the sea chart, sourced from
  Game8's Sea Chart breakdown) rendered as a new "Great Sea atlas" section
  at the bottom of `/islands/`. This is the "lighter collection" alternative
  the original TODO floated, not a standalone page per island — the
  curated 18-entry `islands` collection (main-quest chapters) is untouched,
  still exactly 18 files, still the primary walkthrough.
- **Full Treasure Chart list — closed.** `charts.json` now covers all 46
  Treasure Charts (the original GameCube 1-41 plus HD-exclusive 42-46,
  cross-checked against Thonky's and Game8's independent chart tables, with
  chart 45's Joy-Pendant acquisition confirmed via Hyrule Blog). Also fixed
  a pre-existing inaccuracy found during this research: the
  `treasure-tower-of-the-gods` entry had conflated two separate charts
  (the actual Tower of the Gods chart leads only to Pawprint Isle; the
  Forest Haven Piece of Heart is a *different* chart, from Kamo's
  full-moon-photograph errand on Windfall — now its own
  `treasure-chart-31` entry).
- **Tingle Statues (HD) — closed.** All 5 dungeon locations (Dragon Roost
  Cavern, Forbidden Woods, Tower of the Gods, Earth Temple, Wind Temple)
  are now itemized in the `estatuas-tingle` sidequest card.
- **Nintendo Gallery figurines — expanded, not exhaustive.** Grew
  `figurines.json` from 12 to 27 well-documented entries (added Windfall
  NPCs tied to verifiable photo spots, the 4 remaining non-Ganon/Gohma
  dungeon bosses, and the 5 Legendary-Pictograph purchases from Lenzo). A
  follow-up pass corrected a wrong assumption in this note's earlier
  wording: generic enemy-type figurines are **not** kill-count unlocks —
  Wind Waker has no such mechanic anywhere in its figurine system. Every
  one of the 134 possible figurines, generic enemies included, unlocks the
  same way as the curated 27: showing Carlov a qualifying Pictograph. The
  remaining ~107 non-curated figurines now have their own collection,
  `figurine-monsters` (`{name, location, note?, image?}`), rendered as a
  reference table below the curated one on `/charts`.

  risk), swapped the hand-drawn schematics for real, sourced images, same
  as sibling fan guide sites already do:

  - **Figurine images.** All 27 `figurines.json` entries and all 107
